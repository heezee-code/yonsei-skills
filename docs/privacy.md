# Privacy

Yonsei Skills is an unofficial, skills-only open-source project. The publisher
does not operate a server that receives student records, passwords, session
cookies, uploaded files, or usage logs.

Files and screenshots are processed by the AI product and local environment
the user chooses. That product's privacy terms apply. When a workflow opens an
official Yonsei service, data is sent only to that service as directed by the
student.

Public course-handbook searches send only the requested year, semester,
campus, college, department, and keyword to Yonsei's official public endpoint.
They do not launch a browser or read or send the student's logged-in browser
session. The official page may set its own short-lived anonymous web-session
cookie for the public query.

Do not paste passwords, OTP values, session cookies, or unrelated personal
information into a chat. Report privacy concerns through
[GitHub Issues](https://github.com/mrcha033/yonsei-skills/issues).
